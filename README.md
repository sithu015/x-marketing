# X / AGENCY

X Marketing design study. The mark is two lines: a large **X** and **AGENCY** stretched to the same width.

X Marketing brings honored guests good gifts, bouquets of success, and the light of a bright future. Those gifts are X Marketing itself.

## Run

```bash
npm install
npm run dev
```

## Lockup

- Line 1: `X` — 5 columns, large pitch
- Line 2: `AGENCY` — 38 columns, same width, smaller pitch
- Glyphs are 5×8 dot matrices. Sphere radius is `pitch × 0.44`
- Web and mobile share the same aspect ratio
